## Encounters, geometry and position dependence

Ideal specular reflection preserves the angle to the reflecting face's normal. For parallel faces this preserves whether a ray lies outside the corresponding TIR acceptance; it does not imply the same incidence angle at an orthogonal face. This geometrical interpretation is consistent with the observed large encounter count and modest END-yield gain, but no per-track angular-history analysis was recorded in these campaigns.

The often quoted **0.51546 versus 11.24265** multiplicities are **all-optical forward encounters divided by generated scintillation photons**, a mixed normalization. They are not mean reflections per scintillation track. The consistent all-optical means are **0.48896774 versus 10.66476630 encounters per started optical photon** (D3 versus V1), about **22×** more forward encounters, with the END yield gain quoted above. Encounters include outcomes other than reflection. The sidecar's `0.98^mean` columns are fixed-mean proxies, not a measured ensemble survival probability. D3 and V1 each used N=2000, seeds 26092601 8349041, END-only, 12 workers and eventModulo 1. Evidence: [csv](/home/rrios/ej200_exec26_20260909/build_exec30_20260910/cells/D3/encounter_multiplicity.csv) · [root](/home/rrios/ej200_exec26_20260909/build_exec30_20260910/cells/D3/encounter_multiplicity.root) · [meta.json](/home/rrios/ej200_exec26_20260909/build_exec30_20260910/cells/D3/encounter_multiplicity.meta.json); [csv](/home/rrios/ej200_exec26_20260909/build_exec30_20260910/cells/V1/encounter_multiplicity.csv) · [root](/home/rrios/ej200_exec26_20260909/build_exec30_20260910/cells/V1/encounter_multiplicity.root) · [meta.json](/home/rrios/ej200_exec26_20260909/build_exec30_20260910/cells/V1/encounter_multiplicity.meta.json).

## Runtime data outside the source identity

`src/SiPMModel.cc:42` resolves `$EJ200_DATA_DIR` before the compile-time default. The selected file is `<root>/sipm/AFBR-S4N66P024M_pde.txt`; CMake normally points the default at the tracked source `data` directory. An environment override or edits to runtime copies can change the effective physics without changing the executable or commit. Record the resolved path and file hash. EXEC_31 preserves this loading behavior.

SSLG4 reads `sslg4/macros/oscnt/opsc-101.mac` relative to the process CWD. The initial EXEC_26 attempt lacked that path and failed before event generation with missing `SCINTILLATIONYIELD`: [C023 output](/home/rrios/ej200_exec26_20260909/build_exec26_phase1b_20260909/audit/command_023.log), [command journal](/home/rrios/ej200_exec26_20260909/build_exec26_phase1b_20260909/audit/commands.jsonl). The child return code was **−6 (SIGABRT)**; the Python wrapper propagated it as the shell exit status **250**, explaining the previous report's wording. A new output directory with a symlink to the existing SSLG4 tree produced the completed N=500 run without a physics change. Keep each run's CWD, macro, environment override and data hashes with its ROOT data.

The existing `LogReadoutConfiguration` in `src/RunAction.cc:65` still inspects the obsolete BarSkin and prints `OPEN/UNDEFINED` / `Reflector R: 0` for the explicit-panel geometry. Those labels are not measurements of the reflector. The updated `readout_config_check` checks actual directional panel surfaces, surface type, R=0.98, three versus four panels, and the separate bar-air dielectric interfaces. This known logging limitation is documented without expanding the physics changes.
