## Decision rule declared before any run
The user-supplied criterion is registered here before data collection:

1. If N_pe(R=0.0) and N_pe(R=1.0) differ by **less than 5%**, classify the reflector as inert under this test; the deck’s “Vikuiti ESR R=0.98” claim is not supported by that result.
2. If they differ by **more than 5%**, and the positive control agrees within errors, classify the current implementation as valid under the specified criterion.
3. Any intermediate result must be reported as intermediate without choosing a preferred side.
Operational definitions proposed for approval, to prevent selecting a favorable normalization after seeing data:
- Primary yield: mean detected END PE **per end, per generated event**, `(N_END_L + N_END_R)/2`, including zero-detection events. Also report END_L, END_R, pooled TOP, and total detected PE per event separately. Raw hit-row counts alone are not a valid denominator unless the SiPM detection semantics are checked.
- At each gun position and for each factory, report `delta = abs(mean_R1 - mean_R0) / mean_R0`. If mean_R0 is zero, the ratio is undefined and the relative 5% test is indeterminate; report absolute counts. Exactly 5%, insufficient precision, or a 95% interval spanning 5% is intermediate. No aggregation across positions may conceal a different result at one position.
- Positive control: the explicit `CreateMylarReflector(R)` arm. Report its measured directional air→wrap reflection fraction versus specified R, with event-level uncertainty; at R=0.98 also report A versus B mean-yield differences and their 95% uncertainty. “Agrees within errors” requires both an operational positive control and A/B compatibility; >5% sensitivity alone is insufficient. If the metal control operates as expected but A and B disagree, report the implementation discrepancy rather than declaring A valid. Historical feat/endtop-sslg4 is not this positive control.
- Use all requested x values independently: `{-650,-500,-200,0,+200,+500,+650} mm`. Record event-level standard errors and fixed-seed bootstrap uncertainty where a ratio requires it; do not assume repeated boundary encounters from one photon are independent trials.
- Monotonicity gate: for each factory, position and reported yield, print the adjacent comparisons in ascending R: `0.0 → 0.50 → 0.98 → 1.0`. If an observed required yield decreases, stop the campaign and report the measured reversal with its error; do not silently rerun until monotonic. A noisy reversal is an observed abort trigger, not automatically proof of non-monotonic underlying physics. Report whether END, TOP or total triggered the gate.
- Proposed common Geant4 seed pair: **26092601, 8349041** at every optical setting and position; save the engine name/state. Use one worker for reproducibility, with identical gun and optical settings other than the intended factor. Identical initial seeds do not imply identical subsequent random-number consumption in the two factories. Bootstrap analysis seed, if needed: **26092602**.
