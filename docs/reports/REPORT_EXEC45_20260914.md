## Scope and outcome

This task used existing ROOT files and already published results. No simulation was run. The deliverable explains why two optical-transport defects invalidated earlier aggregate results, how the repaired transport was tested with physical observables, what the tests establish, and what remains outside the validated scope.

The main body contains exactly 12 frames. It contains physical configurations and measurements, but no campaign identifiers, repository paths, hashes, commits, or code excerpts. Seven backup frames provide the requested traceability, physical grid, active contract, real code diffs, Geant4 source semantics, and verified genealogy.

The active physical-observable contract is ready for acceptance: photon production, first-encounter escape, and matched incident-spectrum PDE tests pass in 21/21 cells, and the four qualitative material-filtering conditions pass 4/4. This does not validate an electronics-convolved timing resolution. Historical timing-resolution values are explicitly left unreplaced because they were obtained from transport containing the two defects.
