\begin{frame}{Backup --- hypothesis: the installed boundary mechanism}
For dielectric/dielectric, ordinary polished finish in the tested build:
\begin{itemize}
\item A draw above REFLECTIVITY + TRANSMITTANCE selects absorption.
\item The intermediate interval selects direct transmission.
\item The remaining ordinary-polished branch calls the dielectric/Fresnel calculation.
\end{itemize}
Thus the input coefficient is not directly an observed reflected fraction. The experimental check is the forward census, with nominal input $\MetalR$ but observed reflection $\OldReflection\%$ in \IdROne.
