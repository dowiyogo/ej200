\begin{frame}{Backup: exact observable and width definitions}
\small
For each event, pool the detected photoelectrons over the eight SiPMs at each END and sort by \texttt{time\_ns}:
\[
t_L^{(k)},\quad t_R^{(k)},\qquad
T_0(k)=\tfrac12[t_L^{(k)}+t_R^{(k)}],\quad
\Delta t(k)=t_R^{(k)}-t_L^{(k)}.
\]
Global IDs 0--7 form LEFT and 8--15 form RIGHT. Both sides use the same sorting and event-validity rule; zero count mismatches were found in 210,000 events.
