# BUILD.md — How to compile talk_v5

## Quick build (on host AlmaLinux, via WSL2)

```bash
# 1. On host: regenerate figures (if needed)
source /opt/root/bin/thisroot.sh
cd /home/rrios/ej200
python3 analysis/presentation_v5/scripts/analysis_v5.py

# 2. Copy to WSL2
scp -P 9022 analysis/presentation_v5/talk_v5.tex \
    reriosto@127.0.0.1:/home/reriosto/SHiP/ej200/presentations/presentation_v5/
scp -P 9022 analysis/presentation_v5/figs/v5_*.pdf \
    analysis/presentation_v5/figs/fig*.pdf \
    analysis/presentation_v5/figs/fig_*.pdf \
    reriosto@127.0.0.1:/home/reriosto/SHiP/ej200/presentations/presentation_v5/figs/

# 3. Compile on WSL2
ssh -p 9022 reriosto@127.0.0.1 \
    "cd /home/reriosto/SHiP/ej200/presentations/presentation_v5 && \
     pdflatex -interaction=nonstopmode talk_v5.tex && \
     pdflatex -interaction=nonstopmode talk_v5.tex"

# 4. Retrieve PDF to host
scp -P 9022 reriosto@127.0.0.1:/home/reriosto/SHiP/ej200/presentations/presentation_v5/talk_v5.pdf \
    /home/rrios/ej200/analysis/presentation_v5/talk_v5.pdf
```

## Packages required (WSL2 TeX Live 2020)

- beamer, amsmath, amssymb, booktabs, tabularx, colortbl, tikz, graphicx
- **NOT available**: multirow (removed from v5), colortbl (available)
- Compiles with `pdflatex` only (no XeLaTeX needed)
